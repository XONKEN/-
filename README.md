# 燒金紙 V3.1

GitHub Pages-ready, fully self-contained single-page web app.

- No assets folder required.
- Hand image is embedded directly inside `index.html` as a data URI.
- No backend or API.
- Includes paper selection, paper-rub sound, fire sound, counter, V3.1 label, and MADE BY 永程.

Open `index.html` directly or deploy the folder contents to GitHub Pages.
